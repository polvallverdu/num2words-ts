# num2words-ts

TypeScript port of the Python library num2words (LGPL-2.1-or-later). Bun for development; the
package runs on Bun, Node, Deno, browsers and Cloudflare Workers.

- Upstream, pinned: `.upstream/num2words` (tag/commit in `upstream.json`; CI clones it).
- Porting rules: `CONVENTIONS.md`. Read it before porting or reviewing anything. The two traps:
  Python ints are `bigint` (a `number` is always a float), and converter fields assigned in
  `setup()` must use `declare`.
- Parity: `test/fixtures/*.json` is generated by running upstream Python (`bun run fixtures`);
  `test/parity.test.ts` must match it exactly. `bun tools/parity.ts <code>` for one language.
- Pending work: `python3 -I tools/port/plan.py`. Batch porting: `.claude/workflows/port.js`.
- Checks: `bun test`, `bun run typecheck`, `bun run lint`, `bun run build && bun run compat`.
- Keep every upstream copyright line in ported files (`bun run lint` verifies against upstream).
